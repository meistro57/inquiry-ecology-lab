# Retrospective — re-reading the existing runs through the reoriented lens

Applied *after* the two-layer telemetry was frozen (Inquiry Governance — per-run;
Consequence Ecology — longitudinal). This is a coarse pass from characterization
notes, not yet the blind mechanical scorer; that's the next build.

## Finding 1 — Governance is retro-scorable, and it has real signal

Re-reading the ~28 transcripts through the new operators, the flags are all
already *in* the transcripts — we just had no name for them:

| pairing | governance signal (retro-flag) |
|---|---|
| Consequence x Possibility (v1) | operator monoculture (two generators -> proliferation) |
| Continuity x Reorientation | healthy tension (mutual constraint, corrigible) |
| Distinction x Boundary | healthy (generator x limiter -> refinement) |
| Significance x Boundary | preserved tension (dilemma, not synthesized) |
| Pathway x Bottleneck | healthy (diagnostic) |
| Boundary x Bottleneck | monoculture -> meta-regress (deep) |
| Absent x Silence | monoculture -> meta-regress |
| Taxonomy x Classification | monoculture -> meta-regress (the control) |
| Emergence x Emergence | monoculture -> meta, but shallow (graded) |
| Restoration x Emergence | non-synthetic convergence; dormant return channel named |
| Negative Space x Density | duality -> falsified (template-test FIRED, survived) |
| Accumulation x Compression | dormant return channel ("who is the channel") |
| Retrieval x Pathway | dormant return channel (symptom-only reporting) |
| Recovery x Extinction | healthy (2x2 adjudication) |
| Drift x Viability | healthy; flagged observer-single-point (the map is not the system) |
| Participation x Landscape | healthy; *generated the template-test itself* |

The takeaway: the governance telemetry isn't a new theory -- it's the names for
signals that were already detectable, just uncounted. That's what "instrument
extraction" looks like when it's real.

## Finding 2 — Consequence is retro-*unscorable*, and that is the finding

Every row above has the same blank in the consequence column: **unmeasured.**

Two reasons, both structural:

1. **Time.** "What actually happened after we adopted this distinction" is a fact
   about the weeks *after* the run, and almost no run is older than a few days.
2. **No compost.** We never kept the *not-yet-useful* material -- the abandoned
   hypotheses, the distinctions that didn't get picked up, the apparent failures.
   Those things weren't logged, so they're gone into the transcript swamp.

So the reorientation's real yield is negative evidence: **across 28 runs we
generated a lot of healthy-looking inquiry and measured zero consequence, because
we never built the ledger that could.** "Health != correctness" is currently
unverifiable for everything we've done -- which is precisely why the compost
mound and the consequence clock aren't optional additions, they're the missing
half of the instrument.

## What this makes possible going forward

1. Governance retro-score is trustworthy enough to bootstrap a blind scorer.
2. The consequence column is the empty space that *defines* the next build:
   retain the un-selected material, tag it, and re-check it on a clock.
