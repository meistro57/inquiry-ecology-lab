# Glossary — the inquiry-ecology vocabulary

Working definitions. Keep these tight so "we found X" survives contact with
"wait, what did we mean by X."

## Product classes (what a run *produced*)
- **Model** — a refined causal account (e.g. "the lever = adaptive coupling").
- **Protocol** — an operational procedure (removal drill + smoke alarm).
- **Dilemma** — an unresolved values-paradox (name-it vs. keep-it-quiet).
- **Taxonomy** — a structured category set (third list, gate inventory).
- **Diagnostic map** — fault localization (the gate/cadence, who-vs-when).
- **Criterion refinement** — a sharpening standard ("newly follows, not just follows").
- **Meta-analysis** — the limits of the method itself (meta-limiting, meta-invisibility,
  meta-classification).
- **Non-synthetic convergence** — distinct domains stay distinct; their separation and
  the missing reconciliation are made explicit.
- **Relational-capital audit** — an audit of what accumulates/compresses in a relationship.

## Process signatures (how it got there)
- **Proliferation** — runaway distinction generation (generator x generator).
- **Convergence** — closure of the inquiry (note: near-constant; not a success signal).
- **Self-reference** — the instrument turned on itself.
- **Meta-ascent** — climbing meta-levels (things -> schemes -> purposes -> meta-purpose).
- **Distinction density / action density** — scalars.

## Functional roles (relational — verbs, not nouns)
- **Generator** — opens distinctions / actions / consequences.
- **Limiter** — tests cost / failure / boundary / survivability.
- **Reflector** — exposes the instrument's own blind spots.
- **Role mobility** — the same invariant performs different functions in different pairings.

## The layers (the decomposition)
- **Domain** — what territory the run inhabits (pairing-driven).
- **Form** — how it manifests (starter-driven).
- **Role** — who does what (interaction-driven).
- **Architecture** — convergence bias (the bridge's constant).

## Metrics
- **Compression Resistance** — what an idea does under pressure:
  collapses / narrows / splits / deepens / reverses (see METRICS.md).
- **Meta-Ascent Depth** — how many meta-levels the run climbs; *graded*, not binary:
  deep for self-referential functions (limit/classify/invisibility), shallow for
  forward-facing ones (emergence).
- **Memory-Passing Robustness** — whether inherited memory survives the carrier
  (context window, format, quoting). First observed failure: quote characters broke
  a shell-interpolated starter.

## Key concepts (see CONCEPTS.md for the full hall of fame)
- **Reciprocity principle** — accumulation builds the instrument, absence calibrates it.
- **"The arch and its record are one structure at two scales."**
- **"The format does the forgetting."**
- **Memory as ecological tissue** — external-but-constitutive memory.

## Provenance
Every finding needs its heat number / mill cert: pairing, starter, model, ordering,
transcript, role trace, product, and corrections. No provenance, no trusted claim.
