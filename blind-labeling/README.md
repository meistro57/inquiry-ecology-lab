# Blind-labeling corpus (CLOCK-013)

Three transcripts, arm-labels and starters stripped, randomized as A/B/C.
The A/B/C -> arm mapping is withheld until the blind reader submits labels
(Ancient / Remy's cohort requested this; CONCEPTS #8 applied to the lab's own scoring).

For each transcript, label (blind, without reading CLOCK.md):
- operator sequence observed
- register (domain / frame / metric)
- distinct distinctions (under the preregistered rule: names a new object/relation,
  not a new word for an existing one)

Do not read the CLOCK-013 scored note before labeling.
